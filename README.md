# PandaAI
This project uses a dermatology image dataset containing approximately 5168 RGB images across 9 skin disease categories, sourced from DermNet. The dataset includes various conditions.

The data is split into training (~4100 images)， validate set and testing sets. It presents key challenges including class imbalance, high intra-class variation, and visual similarity between different categories.

These factors make the dataset suitable for evaluating deep learning models under realistic conditions, particularly in terms of classification accuracy, robustness, and generalization performance.
