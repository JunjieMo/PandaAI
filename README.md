# PandaAI
This project uses a dermatology image dataset containing approximately 19,500 RGB images across 23 skin disease categories, sourced from DermNet. The dataset includes various conditions such as acne, melanoma, eczema, and psoriasis, with images exhibiting diverse visual characteristics and resolutions.

The data is split into training (~15,500 images) and testing sets. It presents key challenges including class imbalance, high intra-class variation, and visual similarity between different categories.

These factors make the dataset suitable for evaluating deep learning models under realistic conditions, particularly in terms of classification accuracy, robustness, and generalization performance.
